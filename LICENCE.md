## 🧩 About

**Assetto Corsa Overlay** is a comprehensive overlay for Assetto Corsa featuring performance HUD, telemetry display, quick menu, and config presets.

Based on popular mods like **Content Manager**, **RaceEssentials**, and **Sidekick**.

---

## ✨ Features

### 🎮 Core Overlay
- Performance HUD — real-time speed, gear, RPM, and lap times
- Telemetry Display — throttle, brake, steering, and G-forces
- Quick Menu — access common settings without leaving the session
- Config Presets — save and load overlay layouts
- Session Info — track name, car, and weather conditions

### 🎨 Visual & Layout
- Customizable HUD Elements — toggle and resize widgets
- Color Themes — light, dark, and custom palettes
- Minimap — track map with car positions
- Delta Bar — live delta to best lap

### 🏋️ Practice & Training
- Lap Timer — detailed sector and lap analysis
- Ghost Car — compare against your best lap
- Telemetry Logging — export data for analysis
- Input Display — visualize throttle and brake traces
